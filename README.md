# 灵动岛美化（IOS Dynamic Island Customization）

给带灵动岛的 iPhone 用的美化工具，**免越狱，用巨魔（TrollStore）安装**。

- **应用通知进岛**：选中的应用来通知时，从灵动岛弹出，聊天类通知优先显示发送者头像。
- **歌词**：显示播放器上报的当前歌词，支持逐行填色、淡入等动效；歌名和歌词的颜色分别可调；过长的歌词跟着进度滚动。
- **播放器歌词联动**　宿主在播放信息里提供带时间歌词时，QQ 音乐和网易云音乐适配器按播放进度换句。只上报车载单句的歌曲仍可能慢一句。也可以给同一录音绑定自己的歌词文件。
- **封面转动**：专辑封面像唱片一样旋转。
- **播放进度环**：进度沿胶囊边缘走一圈，颜色可跟随封面。
- **过渡动画**：回弹下落、柔和滑入、淡入、缩放弹出、果冻，五种可选，点一下就能看到演示。
- **覆盖系统岛**：可以盖在系统岛上，跟着系统岛的实际大小自动加宽；系统岛展开时让开。上下位置可在设置里对着真机校准。
- **自定义图标**：应用使用项目内重新绘制的灵动岛图标。

> 项目还在早期，功能以真机表现为准。

## 要求

- 带灵动岛的 iPhone，iOS 16.0 – 16.6.1 或 17.0（巨魔支持的版本）
- 已安装巨魔（TrollStore）
- 界面需要 iOS 16 及以上

旧版有 iPhone 14 Pro Max / iOS 16.6.1 的测试记录。0.6.4 (16) 的普通流媒体取词、微信头像和装机效果仍待对应设备验证。0.6.5 (17) 新增的歌词数据探针只在 macOS 上跑过测试，还没有在真机的 QQ 音乐、网易云音乐里运行过。

## 安装

从源码编译：需要 macOS、[Theos](https://theos.dev)、iOS 16.5 SDK 和 Swift 工具链。

```
FINALPACKAGE=1 make package
```

或者用 Xcode 和 `ldid`（快捷指令的 App Intents 只有这种方式会带上）：

```
IK_SUFFIX=IslandKit-0.6.5 sh build.sh
sh players/build.sh
```

主包为 `packages/TrollSpeed+AppIntents16_2.0-17-IslandKit-0.6.5.tipa`，两个播放器适配器和独立诊断库在 `packages/IslandKit-0.6.5/`。构建机缺少可用模拟器服务时，可用 `IK_PNG_ICONS=1 IK_SUFFIX=IslandKit-0.6.5 sh build.sh` 生成 iPhone 和 iPad 所需的 PNG 图标。`sh devkit/test-players.sh` 在 macOS 上运行适配器、悬浮端和探针的测试。

把 `packages/` 里生成的 `.tipa` 传到手机，用巨魔安装。
安装会覆盖手机上已有的 TrollSpeed（两者使用同一个 Bundle ID）。

## 使用

1. 打开 App，打开右上角的运行开关。
2. 在“应用通知”里勾选要进岛的应用。想只看岛上的显示，到 系统设置 → 通知 把这些应用的“横幅”关掉。
3. QQ 音乐对应 `IslandKit-QQMusic.dylib`，网易云音乐对应 `IslandKit-NetEase.dylib`。播放器加载对应插件后，播放歌曲并打开灵动岛的“歌词”页，查看当前歌曲的数据来源。
4. 如果显示“播放器单句（无时间标签）”或“当前曲目未提供时间轴”，点“为当前歌曲选择歌词文件”，选同一录音版本的 LRC、明文 QRC 或 YRC。文件绑定到打开选择器时的歌曲。可以在该曲下移除绑定。
5. 遇到慢一句时记下播放器版本、录音版本和发生的秒数。打开“歌词 → 导出播放诊断”保存文本。停播后也能导出每个播放器最近 24 种记录。两个适配器已内置诊断，单独观察播放字段时也可用 `IslandKit-PlaybackDiagnostics.dylib`。
6. 手上有播放器导出的歌词样本时，可以点“检查已导出的歌词样本文件夹”，选中该目录，再在当前页点“导出播放诊断”。报告保留路径层次、扩展名、文件大小和文件头类型，目录名和文件名用占位符表示。

### 给 QQ 音乐、网易云音乐取“歌词数据在哪”的证据

这一步只取证，不取词：记录的是类名、方法名、文件形状和时刻，不含歌词文字、歌名和账号。用来确定下一步该从播放器的哪个类、哪个文件拿带时间轴的歌词。

1. 用巨魔安装 0.6.5 的主包（覆盖安装）。打开 App，打开右上角的运行开关。悬浮窗在运行，才能记下系统把每句歌词送到的时刻。
2. 用 TrollFools 给 QQ 音乐和网易云音乐各注入一次 `IslandKit-PlaybackDiagnostics.dylib`（0.6.5 目录里的同一个文件）。之前注入过旧版诊断库的先移除。两个适配器可以留着，也可以不装。
3. 在播放器的设置里打开“车载歌词”或“蓝牙歌词”。
4. 把播放器从后台划掉再打开，停在首页等 10 秒，然后放一首有歌词的歌，连续听 2 分钟以上，中间不要拖进度条。两款播放器各做一遍。
5. 回到灵动岛 App，进“歌词”页点“导出播放诊断”。按钮会显示“正在生成播放诊断…”，最多等约 15 秒，然后选位置保存，把这份文本发回来。
6. 注入后播放器打不开或闪退：在 TrollFools 里把这个插件移除就恢复了，再告诉我们是哪款播放器、哪个版本。

没有注入也能做第 5 步：这时文本里只有“容器里的歌词文件形状”，类清单和播放器一侧的时刻会写 `absent`。

## 已知限制

- 无法关闭系统横幅，也无法隐藏系统自己的灵动岛。
- 锁屏时不显示；只支持竖屏。
- 自动时间轴取决于播放器和曲目是否提供带时间标签的元数据、定时音频歌词或本地同名歌词文件。专有播放引擎可能只上报一行车载歌词，这种情况下自动模式仍可能晚一句。
- 0.6.5 的探针只收集证据，不改变歌词显示。它不解密文件，不调用播放器自己的方法，不读歌词内容，也不联网。
- 微信通知的头像依赖系统通知提供的 `intents-remote-image-proxy`。应用会异步尝试解码代理内容，系统没有提供可读图片时会退回应用图标。

更多实现细节见 [ISLANDKIT.md](ISLANDKIT.md)。
