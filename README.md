# 灵动岛美化（IOS Dynamic Island Customization）

给带灵动岛的 iPhone 用的美化工具，**免越狱，用巨魔（TrollStore）安装**。

- **应用通知进岛**　选中的应用来通知时，从灵动岛弹出。聊天通知优先显示发送者头像，微信还可以按会话绑定备用图片。
- **歌词**　单行显示当前歌词，双行在歌词上方显示歌名。文字可以靠左、靠右，居中时对准整个胶囊的中线（也就是屏幕中线）。也可以选“自定义”，用滑块调左右、上下位置。长歌词跟着进度滚动。歌名、歌词可分别调色，歌词支持逐行填色和淡入。
- **逐句歌词同步**　在 QQ 音乐、网易云里放歌时，悬浮窗按歌名、歌手和时长去 QQ 音乐/网易云的公开歌词接口匹配整首带时间的歌词，再按播放进度换句，不再依赖车载歌词“慢一句”的单句（可关）。匹配不到时仍显示播放器上报的当前句；也可以给同一录音绑定自己的歌词文件，手动绑定始终优先。
- **封面转动**：专辑封面像唱片一样旋转。
- **播放进度环**：进度沿胶囊边缘走一圈，颜色可跟随封面。胶囊变形时环跟着一起变，不会先消失再出现。
- **过渡动画**：回弹下落、柔和滑入、淡入、缩放弹出、果冻，五种可选，点一下就能看到演示。
- **覆盖系统岛**：可以盖在系统岛上，跟着系统岛的实际大小自动加宽；系统岛展开时让开。上下位置可在设置里对着真机校准。
- **自定义图标**：应用使用项目内重新绘制的灵动岛图标。

> 项目还在早期，功能以真机表现为准。

## 要求

- 带灵动岛的 iPhone，iOS 16.0 – 16.6.1 或 17.0（巨魔支持的版本）
- 已安装巨魔（TrollStore）
- 界面需要 iOS 16 及以上

旧版有 iPhone 14 Pro Max / iOS 16.6.1 的测试记录。0.6.7 (19) 的本机测试、包校验和待验真机项目见[本轮验收记录](devkit/验收-0.6.7.md)。

## 安装

从源码编译：需要 macOS、[Theos](https://theos.dev)、iOS 16.5 SDK 和 Swift 工具链。

```
FINALPACKAGE=1 make package
```

或者用 Xcode 和 `ldid`（快捷指令的 App Intents 只有这种方式会带上）：

```
sh build.sh
IK_PLAYER_SDK="$HOME/theos/sdks/iPhoneOS16.5.sdk" sh players/build.sh
```

主包为 `packages/灵动岛美化_<版本号>.tipa`（例如 `灵动岛美化_0.6.7.tipa`），包标识 `com.YiChen.LDDMH`。播放器适配器没有改，继续用 0.6.5 的 `IslandKit-QQMusic.dylib`、`IslandKit-NetEase.dylib` 即可；`players/build.sh` 仍输出到 `packages/IslandKit-0.6.5/`。构建机缺少可用模拟器服务时，可用 `IK_PNG_ICONS=1 sh build.sh` 生成 iPhone 和 iPad 所需的 PNG 图标。

把 `packages/` 里生成的 `.tipa` 传到手机，用巨魔安装。
0.6.7 起包标识改成了 `com.YiChen.LDDMH`，巨魔会把它当成一个新 App 安装，**不会覆盖** 旧的“灵动岛”（`ch.xxtou.hudapp`）。装新版之前，请先在旧版首页关掉运行开关，再在巨魔里卸载旧版；两个都开着会出现两个岛，而且会抢同一个进程记录文件。设置（`com.islandkit.prefs.plist`）和数据目录不变，会沿用。

## 使用

1. 打开 App，打开右上角的运行开关。
2. 第一次打开时，“应用通知”会自动把全部应用都打开（只做这一次，之后完全按你的选择）；列表上方的“全部启用”“全部停用”可以一键切换。想只看岛上的显示，到 系统设置 → 通知 把这些应用的“横幅”关掉。
3. 歌词同步默认开着（“歌词 → 联网匹配逐句歌词”），换歌后约 6 秒开始匹配，不需要注入任何插件。插件是可选的：QQ 音乐对应 `IslandKit-QQMusic.dylib`，网易云音乐对应 `IslandKit-NetEase.dylib`。播放器加载对应插件后，播放歌曲并打开灵动岛的“歌词”页，查看当前歌曲的数据来源。
4. 如果显示“播放器单句（无时间标签）”或“当前曲目未提供时间轴”，点“为当前歌曲选择歌词文件”，选同一录音版本的 LRC、明文 QRC 或 YRC。文件绑定到打开选择器时的歌曲。可以在该曲下移除绑定。
5. 遇到慢一句时记下录音版本和发生的秒数，然后点“歌词 → 导出播放诊断”。报告会保存到 `/var/mobile/Library/IslandKit/playback-report.txt`（和 `island.log` 在同一个目录），同时复制到剪贴板，并弹出分享面板，可以直接发微信或存到“文件”。播放器尚未送来样本也能导出，里面会写明最后的启动阶段、可用的播放器版本和悬浮窗最近的播放事件。两个适配器已内置诊断，单独观察播放字段时也可用 `IslandKit-PlaybackDiagnostics.dylib`。
6. 手上有播放器导出的歌词样本时，可以点“检查已导出的歌词样本文件夹”，选中该目录，再在当前页点“导出播放诊断”。报告保留路径层次、扩展名、文件大小和文件头类型，目录名和文件名用占位符表示。
7. 打开“歌词 → 显示歌词”，在“默认播放样式”选择歌词态、悬挂歌词或紧凑态。悬挂歌词的胶囊只比系统岛高一点：左边方形专辑图、右边音柱，开孔正下方一行居中的小字歌词。紧凑态显示封面和音柱。播放中点按或长按顶部胶囊可以临时切换。“行数”和“文字位置”可直接对照页内预览。“文字位置”选“自定义”后出现左右、上下两个滑块，正在放歌时拖动可以直接在屏幕顶部看到效果，“回到正中”恢复居中。
8. 微信一直显示应用图标时，到“应用通知 → 微信备用头像”，输入通知上显示的会话标题，点“从相册选择”或“从文件选择”。保存成功后会显示一个圆形小预览，从下一条通知起生效。状态行下面有一行小字（来源格式和尺寸、解码方式、存下来的亮度和不透明比例），头像显示发黑时把这一行截图发回来。同名会话共用该图片，可以在同一处移除绑定。
9. 保存头像、导入歌词或导出诊断时提示数据目录不可写，到首页把运行开关关掉再打开（悬浮进程启动时会修好目录），再试一次。`island.log` 里出现 `dataDirectory repaired=1` 就说明修好了。

## 已知限制

- 无法关闭系统横幅，也无法隐藏系统自己的灵动岛。
- 锁屏时不显示；只支持竖屏。
- 联网匹配只发歌名和歌手（歌手字段被车载歌词占用时只发歌名），通过 HTTPS 发给 `c.y.qq.com`、`music.163.com` 的公开接口，只取歌词；不带 cookie、账号或设备信息，对方能看到请求的 IP。结果缓存在 `/var/mobile/Library/IslandKit/NetTimelines/`（最多 400 首，删掉这个目录即清空）。关掉开关就不再联网，也不再用已缓存的联网歌词。
- 匹配宁可落空也不配错版本：现场版、伴奏、翻唱和纯音乐不配；时长差超过 3 秒不配。网易云没有版权的歌（例如周杰伦）会去 QQ 音乐查。配错时手动选歌词文件。
- 11 月 28 日的微信日志里，系统图片代理仍然每次返回 `IntentsErrorDomain 6002`，公开取图接口 5 秒超时，自动头像没有取到。现在能用的是用户为会话绑定的备用图；两者都没有时显示应用图标。

更多实现细节见 [ISLANDKIT.md](ISLANDKIT.md)。
