# 灵动岛美化 0.6.7 (19) · #161 验收

包标识改为 `com.YiChen.LDDMH`，安装包名为 `灵动岛美化_0.6.7.tipa`。巨魔会把它当成新 App 安装，不会覆盖旧的 `ch.xxtou.hudapp`：装之前先在旧版里关掉运行开关、再卸载旧版。

## 逐项结果

| #161 | 改动 |
|---|---|
| 收到通知的过渡动画没了、很奇怪 | 覆盖模式：先在 0.17 秒内收到“刚好盖住系统岛”的紧凑大小（旧内容快照淡出），再按所选过渡风格弹到通知尺寸，结束时通知图标弹一下。下挂模式恢复 0.6.5 的“缩回开孔再长出来”。“淡入”风格原地交叉淡化 |
| 新增“挂在灵动岛上”的歌词样式（IMG_1125） | 默认播放样式新增“悬挂歌词”：胶囊只比紧凑态高 17，左边圆角方形专辑图、右边音柱，开孔下沿一行居中的小字歌词。点按或长按在它和紧凑态之间切换 |
| 巨魔能否检测录屏 | 能：悬浮进程读 `UIScreen.isCaptured`，监听系统的变化通知并每 1.5 秒轮询。开始、结束各弹一次提示；录屏期间没放歌时显示红点和时长，放歌时音柱旁加小红点。外观与动画 → 录屏提示，可关 |
| 安装包和标识符 | `灵动岛美化_<版本号>.tipa`、`com.YiChen.LDDMH`；悬浮进程自检改用自己的包标识 |
| 微信备用头像：从文件选择显示是黑的 | 文件先整个读进内存再解码，统一重绘成 8 位 sRGB 后存 PNG；全透明不保存，缩略图接口全黑时改用整图解码，两条路都全黑时保存并提示。设置页状态行下面显示一行自证信息，`notif.log` 用到这张图时也记一行，两边一对就知道黑在哪一步 |
| 微信备用头像：相册选择报 CoreTransferable 错误 0 | 改用 UIKit 的 `PHPickerViewController`，直接要图片数据，不经过本 App 的临时目录。选图前先确认临时目录可写，不可写时以 root 把这一个目录改回 mobile |
| 通知应用默认全部打开 / 一键全部启用 | 第一次打开（配置里从没选过应用）时自动全选，只做一次；列表上方新增“全部启用”“全部停用” |

| 歌词没有和 App 正常同步 | 悬浮进程按歌名、歌手、时长去 QQ 音乐/网易云公开接口匹配整首带时间的歌词，再按播放进度换句（默认开，可关）；匹配不到时仍显示车载单句。只发歌名和歌手，结果缓存在 `NetTimelines/` |
